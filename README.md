*Projeto em equipe - Scholarship Program Compass UOL (repositório privado da empresa)*

## 💻 Projetos acadêmicos

### 📰 [Última Página](https://github.com/tthaless/UltimaPagina)
Aplicação web de classificados locais inspirada nas últimas páginas dos jornais, onde moradores divulgam e encontram serviços. Tem cadastro e login com senhas criptografadas, CRUD de anúncios, filtros por categoria e bairro e área administrativa para moderação.

**Tecnologias:** Node.js, Express, MySQL, JWT, bcrypt, HTML, CSS, JavaScript e testes com Jest

*Engenharia de Software - em dupla. Também fiz o protótipo no Figma que serviu de base para a aplicação.*

### 🗺️ [Trabalho Prático de Grafos](https://github.com/tthaless/TrabalhoGrafos)
Processamento de grafos e algoritmo para o problema de roteamento **MCGRP**: cálculo de métricas do grafo (densidade, diâmetro, centralidade), caminhos mínimos com **Floyd-Warshall**, solução inicial com a heurística do **Vizinho Mais Próximo** e otimização com **2-opt**, respeitando a capacidade dos veículos. Resultados exportados em CSV e visualizados em Python.

**Tecnologias:** C++, Python, Jupyter Notebook e matplotlib

*Algoritmos em Grafos - em dupla*

### 🖥️ [Simulador Funcional do Processador UFLA-RISC](https://github.com/tthaless/Simulador-Funcional-do-Processador-UFLA-RISC)
Simulador de um processador RISC de 32 bits com montador (assembler), 32 registradores, 256 KB de memória e 30 instruções, além de sistema de logging e framework de testes automatizados com 36 testes aprovados.

**Tecnologias:** Python

*Arquitetura de Computadores II - em grupo*

### ⚙️ [Compilador com Flex e Bison](https://github.com/tthaless/Compilador-Bison-Flex)
Compilador para uma linguagem no estilo C, com análise léxica (**Flex**), análise sintática (**Bison**) e verificação de tipos.

**Tecnologias:** C, Flex e Bison

*Compiladores - em grupo*
